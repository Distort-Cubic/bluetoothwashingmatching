Nn Bluetooth inspection

This prototype discovers an Nn device, asks you to confirm its sticker number, connects, and lists accessible GATT services and characteristic properties. It can passively subscribe to FFE1 notifications and inspect legacy frames. It contains three separate, response-gated service-request identification actions (VI, GV, and GI), but currently keeps protocol writes disabled because the Android source does not reveal the effective GATT write type. The page does not read characteristics, authenticate, or control the machine.

Browser requirements

Use a compatible Chromium browser with Bluetooth enabled. Web Bluetooth requires a secure context, such as http://localhost or HTTPS. Opening this file directly may not provide a supported secure context.
